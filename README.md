# Rubik's Cube

An ongoing project to build a Rubik's Cube simulator and explore algorithms for solving the cube.

The web application uses **HTML and CSS** for visualization and **JavaScript** for the cube's logic and behavior, including moves and animations. Alongside the simulator, the project explores state-space search and algorithms for finding a sequence of moves from a given cube state to the solved state.

**Live demo:** [Rubik's Cube](https://www.ms.mff.cuni.cz/~granskye/rubiksCube/html/index.html)
